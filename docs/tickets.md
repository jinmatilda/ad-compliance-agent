## Ticket 明细

### TK-001：云端项目骨架
- 目标：创建 Linux 可安装的 Python/Streamlit 项目。
- 对应 Spec：§2、REQ-001。
- 允许：`app.py`、`adcheck/`、依赖清单。
- 验收：模块可导入，无 FastAPI/macOS 专有依赖。
- 测试：Python 编译检查。
- 不包含：业务规则。

### TK-002：报告数据契约
- 目标：统一 Finding/Report 以及页面和导出字段。
- 对应 Spec：§4、REQ-002～REQ-008。
- 依赖：TK-001。
- 验收：六个题设字段及置信度、状态、原因、来源可序列化。
- 测试：字段完整性。
- 不包含：匹配逻辑。

### TK-003：规则库与加载
- 目标：`rules.yaml` 严格定义 A-01～A-10。
- 对应 Spec：§3、REQ-009～REQ-018。
- 依赖：TK-001。
- 验收：每条含 ID、名称、描述/匹配、等级、建议、人工默认值；缺失/重复失败。
- 测试：十条集合校验。
- 不包含：LLM 调用。

### TK-004：A-01/A-06 确定性检查
- 目标：词库正则命中原文，A-06 强制拦截人工复核。
- 对应 Spec：§3、REQ-009、REQ-014。
- 依赖：TK-002、003。
- 验收：样例命中且不能被语义结果撤销。
- 测试：A-01、A-06、结论。
- 不包含：图片。

### TK-005：A-02/A-03/A-04/A-08 确定性检查
- 目标：检查数据三要素、优惠双日期/主要限制、免费与费用共现。
- 对应 Spec：§3、REQ-010～012、REQ-016。
- 依赖：TK-004。
- 验收：缺失项写入原因且保留命中原文。
- 测试：四条正常与缺失案例。
- 不包含：真实性认证。

### TK-006：A-05/A-07/A-09 语义审查与降级
- 目标：使用 OpenAI 结构化结果补充语义，并提供本地候选；缺 Key/失败明确转人工。
- 对应 Spec：§3、§6、REQ-013、015、017、019～021。
- 依赖：TK-005。
- 验收：从 `st.secrets["OPENAI_API_KEY"]` 注入；A-09 不判真伪；确定性命中不可撤销。
- 测试：无 Key 降级、候选与结构约束。
- 不包含：保存 Key。

### TK-007：Tesseract OCR 与 A-10
- 目标：从 PNG/JPEG 提取文字、置信度并识别模糊/不完整/失败。
- 对应 Spec：§2、§3、REQ-018、022～026。
- 依赖：TK-002、003。
- 验收：低置信度、无文字、低清晰度、用户标记不完整或 OCR 异常均产生 A-10，结论不得通过。
- 测试：A-10 注入与 OCR 失败边界；系统集成由启动检查验证。
- 不包含：Apple Vision。

### TK-008：合并、评分与导出
- 目标：去重并从同一 Report 生成 JSON/Markdown。
- 对应 Spec：§4、REQ-027～032。
- 依赖：TK-006、007。
- 验收：字段一致；A-06 拦截优先，A-10/降级人工优先。
- 测试：序列化与 Markdown。
- 不包含：页面样式。

### TK-009：Streamlit 单页
- 目标：提供文本/证据/多图输入、规则说明、表格、详情和下载按钮。
- 对应 Spec：§1、§2、§4、REQ-033～040。
- 依赖：TK-008。
- 验收：输入限制、OCR 文字、降级提示、结果和两种导出可见。
- 测试：AppTest 或进程 HTTP 冒烟。
- 不包含：登录和历史。

### TK-010：测试与样例
- 目标：为 A-01～A-10、降级、字段和导出提供可重复验证。
- 对应 Spec：§7、REQ-041～045。
- 依赖：TK-009。
- 验收：测试套件一次运行通过；README 样例覆盖十规则。
- 测试：`python -m unittest discover -s tests -v`。
- 不包含：线上部署宣称。

### TK-011：Streamlit Cloud 部署文件
- 目标：准备 `requirements.txt`、`packages.txt`、Secrets 模板及忽略规则。
- 对应 Spec：§6、REQ-046～050。
- 依赖：TK-010。
- 验收：Linux 依赖可安装；packages 含两项 Tesseract；真实 secrets 被忽略；无硬编码 Key。
- 测试：安装、静态检索、Tesseract 版本。
- 不包含：替用户登录账号。

### TK-012：README、本地启动与部署核查
- 目标：可按说明本地运行和手动部署，清晰区分已验证与待用户线上操作。

- 依赖：TK-011。

- 测试：启动、curl、云阻塞项检索。
- 不包含：声称尚未发生的线上部署。
