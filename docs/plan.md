# 03｜广告宣传材料合规检查助手：需求共识

状态：2026-09-13 用户授权覆盖旧架构并进入完整实现。

## 1. 目标与交付形态

为消费品牌的文字、海报和活动页截图提供发布前第一轮合规检查。主交付为 Streamlit 单页应用，部署在用户自己的 Streamlit Community Cloud 账号，代码托管在用户自己的 GitHub 仓库，形成固定公网 URL；用户 Mac 是否开机不影响访问。应用不构成法律意见。

本次决定替代旧的 FastAPI、Apple Vision、本机 Codex 登录、Mac 固定隧道设计。临时 Quick Tunnel 仅为云平台故障备用，不作为主交付。C01～C03 不再适用。

## 2. 输入

- 中文纯文本、PNG/JPEG 海报、活动页截图，同一广告最多 5 张图联合检查。
- 单图最多 10 MB；正文最多 10,000 字；补充证据最多 5,000 字；正文与 OCR 合计最多 30,000 字。
- 图片用 Linux 可用的 Tesseract OCR；展示识别文字，用户可以复制校正后重新提交。
- 用户声明完整性不能覆盖系统发现的模糊、OCR 低置信度或截图不全。
- 不支持 PDF、视频、动态页面、网址抓取及批量独立广告。

## 3. 规则与边界

A-01～A-10 首期全部实现。确定性规则覆盖 A-01、A-02、A-03、A-04、A-06、A-08、A-10；OpenAI 补充 A-01、A-05、A-07、A-09 语义审查。A-05/A-07/A-09 同时保留本地候选检测。

A-06 强制拦截并人工复核；A-09 只要求真实性和授权材料并转人工，Agent 不判真伪；A-10 证据不足不得判为未发现风险。LLM 不得撤销确定性命中。没有 API Key 或调用失败时，确定性规则继续运行，A-05/A-07/A-09 明确显示语义审查降级并转人工。

## 4. 输出

每项风险包含：风险内容原文、风险类型、对应规则、风险等级、修改建议、是否需要人工审核；另含规则名称、判定状态、置信度、原因和来源。页面提供表格、详情及 JSON/Markdown 导出。无命中仅显示“未发现题设规则风险”，不声称法律合规。

## 5. 部署与账户

- 用户注册/使用 GitHub 与 Streamlit Community Cloud 账号。
- 用户从 OpenAI API Platform 创建自己的 API Key，在 Streamlit Cloud Secrets 中配置；真实 Key 不进入 Git。
- 云端通过 `requirements.txt` 安装 Python 依赖，通过 `packages.txt` 安装 `tesseract-ocr` 和 `tesseract-ocr-chi-sim`。
- 固定 URL 形式为 `https://<用户选择的子域名>.streamlit.app/`。

## 6. 验收

1. Streamlit 单页可接收文本和最多 5 张图片，Tesseract OCR 可用。
2. A-01～A-10 均有可复现样例；每项输出字段完整。
3. A-06、A-09、A-10 满足强制处置；API Key 缺失有可见降级。
4. 页面、JSON、Markdown 使用同一报告对象。
5. 本地测试通过，服务可启动且 localhost 返回 HTTP 200。
6. GitHub 仓库不含真实密钥；Streamlit Cloud 可根据 README 手动部署。
7. 在线 URL 只有用户完成账号登录、仓库推送和 Secrets 配置后才能实际验证，不把本地验证冒充线上通过。

## 7. 非目标与风险

不做账号系统、多人审批、自动发布、法规库、真实性自动认证、历史持久化和特殊行业法律结论。OCR、语义模型和启发式检测可能误报漏报，所有发现均供人工复核。Streamlit 免费服务可能冷启动；OpenAI API 需要可用额度。

## 8. 追溯

需求来源为题目 A-01～A-10、候选人现场试用验收标准，以及用户在 2026-09-13 明确授权的云架构覆盖决定。本文件只改变交付形态和部署方式，其余已确认业务范围、输出字段和人工审核边界保持不变。
